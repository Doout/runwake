# Security

Do not open a public issue containing credentials, private logs, kubeconfigs, or
details that would make an unpatched vulnerability easier to exploit.

Use GitHub private vulnerability reporting when it is available for this
repository. For non-sensitive security hardening, open a regular issue.

The supported security boundary for `0.1.x` is documented in
[`docs/security.md`](docs/security.md). Remote agents are not supported in this
release.
